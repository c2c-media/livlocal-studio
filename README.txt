LivLocal contact form — 2026-10-07
==================================

Files in this package (repo-relative paths):

  api/contact/index.js   NEW. Receives the form post, checks it, forwards it to the
                         Notion Worker, which files it in LivLocal Messages.
  build.js               Contact page: the "Open the form" button is replaced by a
                         real form (name, email, topic, message) beside the email card.
  src/main.js            Submits the form, shows the thank-you or a failure message.
  src/styles.css         Styles for the form fields, the hint, and the status line.

Before the form works, one Azure setting is required
----------------------------------------------------
Static Web Apps -> Configuration -> Application settings -> New application setting

  Name:   CONTACT_WEBHOOK_URL
  Value:  https://5759979790.webhook.notionusercontent.com/webhooks/worker/11515752-510e-8164-ba4f-0003ac7c99c7/01a11832-3f08-71f4-b019-c1e35f6512c4/24-om04mAywEBbru/onContactForm

The value is the contact-form webhook from the Notion Worker. It lives in app
settings rather than the repo so it is not public. Without it, the form shows
"not set up yet" and points at the email address.

Nothing else to configure. The Worker already holds its Notion token, and
submissions land in LivLocal Messages with Status set to New.
